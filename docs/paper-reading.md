# FREEDOM 阅读与手算

核查日期：2026-09-29。作者 Xin Zhou、Zhiqi Shen；ACM MM 2023。预印本首次提交 2022-11-13，本文以 2023-08-23 的 v3 为阅读版本。[论文与版本](https://arxiv.org/abs/2211.06924v3)；[全文](https://arxiv.org/html/2211.06924v3)。

## 研究问题与公式入口

FREEDOM 考察多模态推荐是否必须持续学习商品图结构，以固定图降低开销，并对交互图进行度敏感剪枝。阅读时按 §3.1 Eq.1–3（原始特征余弦、二值 kNN、图文结构混合）、§3.2 Eq.4（交互二部图及剪枝）、§3.3 Eq.5–10（两图传播和 BPR）、§3.4 Eq.11（内积排序）依次对照代码。原论文结果属于其完整数据及实验条件，不能当作本项目子集的预期指标。[方法全文](https://arxiv.org/html/2211.06924v3)

项目中的图像/文字是预提取向量；CPU 仍要训练用户/商品 ID、特征表和投影层。固定的是初始化内容图，并非冻结全部参数；官方 `Embedding.from_pretrained(..., freeze=False)` 允许特征表更新。图像补全先于推荐训练，并会改变该次运行的初始内容图。代码对应及偏离见 [reproduction-map.md](reproduction-map.md)。

## 手算例一：三种图如何区别

以下数字是教学构造，不是真实商品或实验结果。训练交互：用户 U0 购买 A、B；U1 购买 A、C。交互矩阵（列 A/B/C）为：

```text
R = [[1,1,0],
     [1,0,1]]
RᵀR = [[2,1,1],
       [1,1,0],
       [1,0,1]]
```

**补全图**去除对角后，Top20 在此小例没有截断：`N_A={B,C}`，`N_B={A}`，`N_C={A}`；这是用户共交互决定的邻居，与图像余弦无关。

**交互图**中 U0/U1 的度均为2，A 的度为2，B/C 的度为1。归一化边 U0→A 权重为 `1/sqrt(2*2)=0.5`；U0→B 为 `1/sqrt(2*1)≈0.7071`。剪枝抽样中前者的相对权重更低。若暂用一维 ID 嵌入 `A=2,B=4,C=6`，U0 的一层传播为 `0.5*2+0.7071*4≈3.8284`；实际模型还会平均第0层和后续层。

**内容图**若图像向量为 `A=(1,0), B=(0.8,0.6), C=(0,1)`，余弦 `s(A,B)=0.8`、`s(A,C)=0`。教学令 k=2，A 会连接自身与B，因为官方内容 kNN 保留自邻居；默认实际 k=10。不能将补全共交互图的“去自边”规则搬到 FREEDOM 内容图。原代码 `torch.topk` 的余弦并列不额外按 ID 排序。

## 手算例二：缺图均值、收缩与排序损失

构造缺图目标 X，其图邻居四个，仅 J 可见且 `v_J=(8,2)`；另一个非邻居 K 可见且 `v_K=(0,6)`。全场景仅 J/K 可见，所以 `mu=(4,4)`，目标 `d_X=4,n_X=1`。隐藏邻居不提供原向量：

| 方法 | X 的补全 |
|---|---|
| zero_fill | `(0,0)` |
| global_mean | `(4,4)` |
| paper_neighmean | `(8,2)/4=(2,0.5)` |
| observed_mean | `(8,2)/1=(8,2)` |
| fixed_mix，alpha=0.5 | `(6,3)` |
| support_mix，tau=4 | `((8,2)+4*(4,4))/5=(4.8,3.6)` |

同一场景中另一个缺图目标没有可见邻居：`observed_mean/fixed_mix/support_mix` 回退 `(4,4)`；`paper_neighmean` 给零（有邻居但都置零；孤立节点的零输出为本地约定）。X 的新补全不会再充当别的目标的邻居证据。这里的 `n=1` 只表示一条证据，并非置信概率。

再取一个独立的 BPR 数字例：用户表示 `(1,0)`，正商品最终表示 `(2,1)`，负商品 `(0,1)`。分数为2与0，BPR=`-log(sigmoid(2))≈0.1269`；交换正负后约2.1269。模型用真实训练正样本和训练未交互负样本推动前一种排序，并加图像/文字辅助 BPR。`reg_weight` 在该实现是辅助 BPR 系数，不能读作额外 L2 项。

## 本项目能回答什么

预定研究以配对掩码、种子和训练预算比较 `uniform30/tail30` 与六种补全；目前只完成五次开发运行。`clean` 仅表示没有新增遮蔽；作者预处理未提供原生缺图名单，非零向量不证明原图存在。实测指标与未完成部分见 [阶段报告](findings.md)，不能从教学例或论文数字推断。新颖性边界见 [related-work.md](related-work.md)，来源见 [data-provenance.md](data-provenance.md)。
